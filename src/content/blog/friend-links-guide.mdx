朋友页由三部分组成：友链分组、朋友圈聚合和友链申请。友链数据在 `src/data/friends.ts` 中维护，卡片视觉由主题组件统一渲染。

## 友链分组

```ts
export const friendLinkGroups = [
  {
    title: '技术伙伴',
    description: '写代码的人，和他们的博客。',
    items: [
      {
        name: '一叶之秋',
        url: 'https://example.com/blog',
        bio: '示例友链：记录折腾与思考',
      },
    ],
  },
];
```

每项支持 `name`、`url`、`bio`、`avatar`、`rss` 和 `sticky`。没有头像时，卡片会使用名称首字母作为占位。

## 在 MDX 中使用卡片

`FriendLinkCard` 也可以在文章正文中直接使用：

<FriendLinkCard

## 朋友圈

朋友圈默认按以下顺序取数据：

1. `src/config/site.toml` 中 `[config.friendCircle].feed_src` 指向的订阅源
2. `public/friend-circle.json`（自行同步或生成的聚合文件）
3. 构建期抓取友链的 RSS / Atom
4. 内置演示数据 `src/data/friend-circle-demo.json`

```toml
[config.friendCircle]
feed_src = ""
pageSize = 20
```

`feed_src` 可以是 URL，也可以是 `public/` 下的文件路径。没有配置时，构建会尝试抓取友链里带 `rss` 的站点；全部失败则展示演示数据。

## 友链申请

友链申请表单由 `site.repository` 指向的 GitHub 仓库生成 Issue。仓库地址为空或不可解析时，申请区不会显示。提交的 Issue 通过 `friend-link` 标签归档，博主确认后把友链加入 `src/data/friends.ts`。

朋友页的标题、kicker 和副标题在 `src/config/site.toml` 的 `[config.pages.links]` 中配置。
